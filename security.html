Security

Security is an authority problem.

Hagon is being designed so that tenant boundaries, target authorization, identity, ownership, lifecycle, and history are enforced as product authorities, not just interface conventions.

Tenant isolation

Customer-owned records are tenant-scoped, with PostgreSQL row-level security used where applicable.

Authorized targets

Recon operates only on enabled targets inside an enabled external scope backed by active authorization.

Evidence boundaries

Recon observations remain separate from Findings and Score until Validation establishes a supported conclusion.

Least privilege

Runtime roles are intended to receive only the permissions needed for supported application paths.

Immutable history

Lifecycle, ownership, remediation, delivery, and Score histories are designed to preserve an accountable record.

Responsible disclosure

A public vulnerability-reporting channel will be published before general availability.

Private alpha notice

Public security documentation, compliance claims, and vulnerability-reporting contact details are not yet finalized.
